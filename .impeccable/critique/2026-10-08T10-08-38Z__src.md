## Design specificity
Mostly authored (up from half): before/after evidence at every decision, a trend that stays meaningful when caught up, "was Low", an honest Stop dialog, the review queue. Still generic: the Monitoring page skeleton, the company heatmap (2 of 365 cells coloured), and the main table, whose page 1 is 25 identical red rows.

Detector: CLI 3 advisory false positives (ViewReport.tsx:112, :408 ×2, documented). Overlay on 5 desktop + 2 mobile pages: nested-cards ×11 (false positives: header/footer bands, table heads, date dividers; field diff box documented), clipped-overflow (false positive: hidden screen-reader table), overused-font and repeated "companies" (false positives), tiny-text (now documented), first-viewport-column-overflow at MonitorDetail.tsx:246 (accurate, mitigated by sticky aside), cramped-padding (false positive), mobile text-overflow ×5 at Monitoring.tsx:556 (deliberate ellipsis, but no title, so the full name is unreachable).

## What's working
1. Before/after evidence wherever a decision is made, mapped to the report section.
2. A closed review loop: queue with "1 of 133", Next, buying a report pre-fills Actioned.
3. Severity Settings: drafts survive navigation, impact shown before saving, Undo and who-changed-what.

## Priority issues
- [P1] Bulk review allows blind, blanket decisions on High changes. The overflow line "and 18 more changes, less severe" is false when the overflow is High (Review.tsx:65; introduced in the previous round). Company count includes selected companies with nothing to review. No note required for High "No action needed"; select-all-1,248 unguarded. Fix: severity breakdown in the overflow line, group by severity, require a note for High no-action, confirm above ~50, count only companies with reviewable changes. → /impeccable harden
- [P1] Focus and selection break the keyboard loop: no focus return after r (row review dialog has no onDone, verified), after Stop on the company page, after saving Settings, and on page changes (document.title never changes). Reviewed companies stay selected. Fix: focus next row's Review link after r, prune or report off-page selection, per-page titles and h1 focus on navigation, focus status notice after Stop and footer after Save. → /impeccable harden
- [P1] The main table hides the change itself: pill + chips only, 25 identical red rows. Fix: one-line truncated before/after under the chips; within a tier, Status and Ownership first, then newest. → /impeccable layout
- [P2] Active monitors and Change feed triage differently (feed has no bulk select, keys, search, page size/jump; severity chips vs dropdown; export placement). Fix: one filter bar, footer and key map across tabs. → /impeccable polish
- [P2] Baseline-only comparison and contradictory demo data (hidden intermediate status, no-change name diff, "No action needed" with an "ordered a report" note). Fix: "Last known" or "Since your last review" column; clean demo generator. → /impeccable clarify

## Persona red flags
